One resignation letter, exactly one line: an aquarium keeper resigns because the octopus has learned his locker combination and, frankly, earned the promotion — a small concrete scene with a specific job, a surprise twist at the end, and a punchline that leaves the narrator worse off (replaced by the octopus), written to read like a letter someone could really send.
